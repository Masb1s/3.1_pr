## 2. Журнал використання

1. Етап: Налаштування TLS.
Мета: вирішити помилку Algorithm is missing при підключенні OpenHAB до брокера
Промпт: "OpenHAB MQTT binding error Algorithm is missing when using certificate path"
Що взято: ідею прибрати параметр certificate і додати hostnameValidated=false
Що змінив: перевірив логи openhab.log, міст MQTT став ONLINE

2. Етап: Написання симулятора.
Мета: створити генерацію телеметрії та обробку команд
Промпт: "Python paho-mqtt simulator with realistic noise and Last Will"
Що взято: шаблон класу та функція publish_telemetry
Що змінив: додав унікальний client_id, щоб сценарії не відключали основний симулятор

3. Етап: Написання правил.
Мета: зробити таймери для режиму Економ та тривоги
Промпт: "OpenHAB 4 rules DSL timer global variable"
Що взято: пораду використовувати cache
Що змінив: це не працювало, тому переписав на використання Items

## 3. Помилки ШІ

- Для уставки температури ШІ порадив використовувати Switch. Це викликало помилку, бо OpenHAB чекав число. Я замінив на Number Item
